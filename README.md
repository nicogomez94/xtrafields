# X-TRAFIELDS

Sitio de presentación para una constructora de estadios, canchas y superficies deportivas.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión final:

```bash
npm run build
```

El contenido se puede ver en español, inglés y griego. El idioma elegido se guarda en el navegador.
